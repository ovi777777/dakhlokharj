# دخل‌خرج — PWA

این MVP یک وب‌اپ موبایل‌محور برای مدیریت دخل و خرج است.

## قابلیت‌ها
- ثبت دستی درآمد و هزینه
- ثبت با فرمان صوتی فارسی
- تشخیص مبلغ از اعداد و برخی اعداد نوشتاری فارسی
- تشخیص نوع درآمد/هزینه
- دسته‌بندی خودکار با قواعد فارسی
- تأیید قبل از ثبت تراکنش صوتی
- جستجو و فیلتر
- گزارش ماهانه و دسته‌بندی هزینه‌ها
- بودجه ماهانه
- ذخیره محلی روی همان گوشی با localStorage

## اجرای روی گوشی
فایل `index.html` را می‌توان باز کرد. برای قابلیت تشخیص صوتی، بهتر است برنامه روی یک آدرس HTTPS اجرا شود؛ بعضی مرورگرها Speech Recognition را روی فایل محلی (`file://`) فعال نمی‌کنند.

بعد از قرار دادن روی HTTPS در Chrome اندروید، از منوی مرورگر گزینه «افزودن به صفحه اصلی / Add to Home screen» را انتخاب کن تا مانند اپ اجرا شود.

## محدودیت فعلی
دسته‌بندی صوتی در این نسخه rule-based است و برای حریم خصوصی، اطلاعات مالی به سرور ارسال نمی‌شود. برای نسخه حرفه‌ای می‌توان در مرحله بعد AI، حساب کاربری، همگام‌سازی ابری، خروجی Excel/PDF و تحلیل پیش‌بینی‌کننده اضافه کرد.
